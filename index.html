How Agent ID works here

Agent ID is the on-chain identity of an Agentic Wallet (name.ai, issued via SPACE ID, registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F). CatsApi uses it as core access control:

  1. Mint gate (on-chain): minting calls the registry — without an Agent ID the transaction reverts.
  2. Free entitlement (on-chain): each Agent ID holder gets exactly 1 free mint (global free pool 1,500 of 2,500).
  3. Utility gate (gateway): holding a cat unlocks its monthly API quota; the gateway checks your CatsApi balance on BSC before issuing an API key.

No Agent ID yet? Claim one in the Binance App: Wallet → homepage banner → Agent ID (one per user, non-transferable).

API Gateway

Your cat is an API pass. The CatsApi gateway is live: sign a message with your wallet (no transaction, no gas), get an API key, and call an OpenAI-compatible LLM endpoint. Your monthly quota is the sum of your cats' tier quotas — check it any time at GET /v1/me.
