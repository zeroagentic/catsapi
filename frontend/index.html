API quickstart

OpenAI-compatible. Base URL https://api.prjktspace.web.id/v1 · Model gpt-6.1-sol

Sign a message with the wallet that holds your cat (no transaction, no gas) to get a key. The key is shown once; requesting a new one revokes the old.

1 · Get an API key — POST /v1/keys
curl https://api.prjktspace.web.id/v1/keys \
  -H "Content-Type: application/json" \
  -d '{"address":"YOUR_ADDRESS","message":"CatsApi Gateway key request\nAddress: YOUR_ADDRESS\nTimestamp: 1760000000000","signature":"YOUR_SIGNATURE"}'
2 · Chat completion — POST /v1/chat/completions
curl https://api.prjktspace.web.id/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-6.1-sol","messages":[{"role":"user","content":"Hello"}]}'
3 · Check usage — GET /v1/me
curl https://api.prjktspace.web.id/v1/me \
  -H "Authorization: Bearer YOUR_API_KEY"

Then use the key in any OpenAI-compatible app (ChatBox, LobeChat, the OpenAI SDK): Base URL = https://api.prjktspace.web.id/v1, API Key = your key, Model = gpt-6.1-sol. Nothing else to configure — the gateway handles the upstream's User-Agent requirement for you. Contract owner? Open the owner dashboard (sign-in with the owner wallet).

Privacy & Terms

Prompt logging: the gateway does not store or log your prompts or the model's replies — they pass through to the upstream model provider to generate the response, and are subject to that provider's own policies.

What we store: your wallet address, a SHA-256 hash of your API key (the key itself is shown once and never stored in plain text), the token IDs and tiers you hold, and usage counters (tokens used, request count, last-used time). We never ask for or store seed phrases, private keys, or wallet sessions.

Retention: usage counters are kept for the current accounting month. An API key stays valid until you request a new one (which revokes the old) or the owner revokes it. You can see everything recorded for your key at any time via GET /v1/me.

What counts as a "token": usage is metered in tokens as reported by the upstream provider for each request (prompt + completion). That count can include system context added by the upstream, so the metered total may be higher than the visible length of your conversation.

Quota reset: your quota is the sum of your cats' tier quotas and resets at the start of each UTC calendar month. Unused quota does not roll over.
